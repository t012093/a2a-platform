# 主要フロー（MVP）

## 1. RFP作成〜見積取得
1. 依頼側がRFPを作成（draft）
2. 依頼側がRFPを承認（approve）
3. プラットフォームがA2A SendMessageで複数エージェントへ配信
4. エージェントがTaskを返却（交渉開始）
5. OfferをArtifact/DataPartで受領
6. `TASK_STATE_INPUT_REQUIRED` の場合は追加情報を送信

## 2. 交渉〜契約
1. 依頼側が見積を比較
2. 追加情報が必要な場合、`INPUT_REQUIRED`で再質問
3. 条件合意後、契約サマリー（Contract Artifact）を生成
4. 双方が契約を承認
5. 契約承認期限は7日（期限切れは`expired`）
6. 承認期限に対してリマインド通知（2日前/1日前）

## 3. 決済（エスクロー）
1. 依頼側がエスクローへ入金（escrowed）
2. 代理店側が作業開始
3. 成果物納品後、依頼側が受領承認
4. レビュー期間（7日）内に承認 or 差し戻し
5. 支払いリリース（承認後 or 自動承認）
6. PSP Webhook で決済状態を反映（MVPはStripe）
7. 支払いリリース承認のリマインド通知（2日前/1日前）

## 4. 例外フロー
- 期限切れ: 見積返信なしの場合は自動クローズ
- 変更契約: 追加要件が出た場合は再見積→再承認
- 紛争: 納品後に合意できない場合は管理者裁定（7営業日以内）→部分リリース/返金
