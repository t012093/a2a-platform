# MCP連携方針（将来拡張）

## 1. 位置づけ
- A2Aは「エージェント間の通信」
- MCPは「エージェントが使うツール/データへの接続」
- 本プラットフォームはA2Aを主軸に、MCPは“必要最小限”から導入する

## 2. 想定ユースケース
### 2.1 プラットフォーム内部ツール
- RFPテンプレ生成
- 契約サマリー生成
- 既存案件の参照

### 2.2 外部エージェント側ツール
- 競合調査/市場データ
- 画像/素材管理
- 翻訳・ローカライズ
- 法務/広告表現チェック

## 3. 導入方針（段階的）
- Phase 1: 内部ツール1〜2個のみ接続
- Phase 2: 外部エージェント向け接続の許可
- Phase 3: MCP接続先のマーケット化（審査制）

## 4. 運用・ガバナンス
- 接続先は「審査/許可制」
- データ送信範囲を明確化（PII/機密除外）
- MCP呼び出しログは監査ログに集約

## 5. MVPの判断
- MCPの枠組みは設計に含める
- 実装は最小限に抑える（コストと複雑性の抑制）
